# Agent Skills illustration prompts

These are the final prompts used with the built-in ImageGen tool for the text-free illustration
layers in `agent-skills-tutorial/layers/`. Exact titles, subtitles, section badges, and watermarks are
added by `render_concept_cards.py`, so no generated typography appears in the published cards.

## Shared art direction

```text
Use case: stylized-concept
Asset type: text-free 16:9 educational article chapter-card illustration
Scene/backdrop: airy white studio with pale-blue geometric platforms and generous upper-left
negative space for a later title overlay
Style/medium: polished soft 3D isometric editorial illustration, rounded precise forms, cohesive
technical-education series
Lighting/mood: soft daylight, calm and confident
Color palette: white, ice blue, navy, teal, with a tiny coral accent
Constraints: no text, letters, numbers, logos, brands, watermarks, code glyphs, or legible UI;
professional rather than childish
Avoid: dark backgrounds, clutter, photorealism, floating gibberish
```

## Per-card subjects

1. **A skill is a playbook:** A capable AI teammate opens a concise blue operations playbook beside
   a small toolbox and repository documents.
2. **Progressive disclosure:** Three nested stages reveal an identification card, an opened
   playbook, and a drawer of optional scripts, templates, and references.
3. **Skill anatomy:** An exploded-view package separates a central instruction sheet, a scripts
   tool module, a reference-book module, and a template/image module.
4. **Plan, validate, render:** A left-to-right pipeline turns change cards into structured evidence,
   passes a validation gate, and becomes a polished release-notes page.
5. **Portable core:** One central playbook branches to two distinct, unbranded agent workstations
   through thin adapters.
6. **Explicit and implicit activation:** One deliberate selection path and one automatic
   speech-bubble matching path activate the same playbook.
7. **Find and share:** A curated library of skill packages is inspected with a magnifying glass
   before a selected package travels to an open sharing box.
8. **Trust boundary:** A skill package passes through a transparent inspection chamber and shield;
   suspicious coral fragments are stopped before the agent workstation.
9. **Host comparison:** One agent and one playbook connect to five distinct, unbranded host stations
   arranged around a shared platform.
10. **Quality loop:** Test artifacts, a magnifying lens, adjustment tools, and verified output form
    a clockwise loop around a central playbook.
